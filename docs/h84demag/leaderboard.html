The real leaderboard, and a flagged irregularity

Irregularity (flagged, not hidden): the brief that started this session quoted per-repository scores for the GEMSDOE/1–88 sibling lineage (e.g. "h33-h33-2-b2: 0.2778", "0.3195 is the highest score right now") as if they were competition results. We opened the source repository for the highest-quoted one (GEMSDOE32) and its own README says, verbatim, in bold: "No organizer score exists for this or any artifact here — every number is a local proxy measurement." (source, fetched 2026-10-22). We independently fetched the real public leaderboard (table below) and no participant name from this lineage appears in the top 50. No session in this lineage, including this one, has ever had a DrivenData account. Treat every "GEMSDOE-site score" quoted anywhere, including in future prompts, as HOLDOUT-DTI (a local proxy) unless a literal submission-page receipt is attached.

Why this matters for strategy

If future sessions keep optimizing against each other's self-reported local proxies, the lineage can drift arbitrarily far from the real objective (DTI against the organizer's private test set) without anyone noticing, because there is no feedback loop closing the gap. The only way to close it is either (a) a real DrivenData account submitting into the competition and reporting back actual receipts, or (b) treating every local number as exactly what it is — a proxy — and spending effort on holdout-construction quality (see Suggested next steps) rather than chasing another session's unverified high-water mark.
