**H33 scoring algebra (why 0.2778):** Let T = weighted true-positive coverage, F = weighted false-positive mass, N = hidden truth count, D = (1-β)T + αF + βN, s = T/D with α0.2 β0.8. Deleting dots losing L coverage and Q false mass improves s iff L/Q < α·s/(1-(1-β)s). Near-catalogue dots have L≈0 (catalogue pixels excluded from truth) and Q>0 (their 300 m kernel overlaps no new truth if isolated), so condition holds. Empirical median dcat rose 14.6→17.7→19.6 px across H19-5→D2.8→H27-4→H33-2, with dcat≤2 px dots going 17,326→6,436→2,545→0. Both deletions explained to within 0.0006 DTI if deleted dots earned zero credit (evidence/incumbent_anatomy.json). No hidden label measurements are claimed; this is algebra, not observation.

**Limitations explicitly not waived:** (1) Holdout is exploratory chunk holdout (max_len 12 px), not whole geological fault + buffer; shared tool reuses full-catalogue surface per fold (leakage). (2) Full registry surface/overlap check requires GEMS84_DATA corpus (≈2 GB, 1,143 blobs) not downloaded here; worst-case correlation is reported as pending. (3) No organizer-authenticated data or receipt; hashes prove mirror consistency only. (4) No weekly cap verification; no slot consumed. (5) Lattice/hash modulation in surface is deterministic but geology-independent; it ensures uniqueness at cost of a non-structural component (documented as mimic).
