Evidence categories used here

  • Official source: a page maintained by the organizer or public agency. It supports only claims actually present on that page.
  • HOLDOUT-DTI: must include evaluator version, number of withheld positives, and 95% confidence interval. No value is available in this checkout.
  • ORGANIZER-CONFIRMED: only a result copied from a submission-page receipt. None is present here.
  • Owner report / projection: useful for prioritizing what to reproduce, but not an organizer-confirmed score and not a holdout result unless its exact evaluator protocol and artifacts are accessible and reproduced.
