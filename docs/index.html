Both deletions are explained to within 0.0006 DTI if deleted dots earned zero credit: let T = weighted truth coverage, F = false mass, N = hidden truth, D = (1-β)T+αF+βN, s=T/D. Deleting L,T coverage and Q,F mass improves s iff L/Q < α·s/(1-(1-β)s). Near-catalogue dots have L≈0, Q>0, so pruning helps.
