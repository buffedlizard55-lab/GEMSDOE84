Why H33 may have improved

The upstream H33 evidence starts from an inherited GEMSDOE28 base and removes low-credit predictions near mapped faults. Under pooled DTI, deleting redundant dots can reduce false-positive mass more than true-positive coverage. This is a precision-budget mechanism, not proof of a new physical detector.

Its user-reported score is not organizer-confirmed here. The hidden truth is unavailable, so exact causal attribution or a guarantee of improvement is impossible. Earlier claims of precisely quantified hidden credit and guaranteed higher performance are not endorsed.

For fixed positive count G: DTI = t / ((1-beta)t + alpha*f + beta*G). The shared evaluator uses alpha=0.2, beta=0.8 and a 300m triangular kernel. Those settings are repository configuration; this session did not retrieve the official metric page. The official reference notebook confirms training loss weights, not the distance evaluator.
