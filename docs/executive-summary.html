Steps

  1. Log in and open the competition (drivendata.org/competitions/306/competition-doe-gems/), then go to its submissions area. (This sandbox cannot load DrivenData pages, so no deeper URL is quoted.)
  2. This lane has no file to submit (see the front page). When a lane does produce a cleared file, download it from that lane's front page and check its sha256sum against the run card.
  3. Click Submit → File to submit → choose the .tif (or the .zip holding exactly one TIFF).
  4. Paste the lane's Note (≤ 140 characters, e.g. “clustering with k=25”) and keep the file stem as the submission name.
  5. Submit, then copy the score from the submission page receipt into registry/live_scores.csv as ORGANIZER-CONFIRMED.
