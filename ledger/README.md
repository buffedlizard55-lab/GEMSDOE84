# Ledger

`submissions.csv` is generated by `scripts/build_ledger.py` (do not hand-edit
historic rows; the human fills only `receipt_score` and `date` for BUILT rows
after submitting, then re-runs nothing — edit those two cells and commit).

- Historic rows come from `registry/live_scores.csv` (103 owner-reported live
  scores). Evidence class is **CLAIM** for every one: this repo holds no
  submission-page receipts, so `receipt=N` throughout, including R0's 0.2778.
- Exact-repeat twins differing only by `-nan`/`-zeros` suffix are collapsed
  (1 pair collapsed by name: `849a0f04` nan+zeros). Further repeats exist
  across sites under different names (e.g. sha8 `8acb75e1`, `7f00890a` recur);
  they are left as separate rows because collapsing them needs the files,
  not the names. Counting wasted slots from names alone is a lower bound.
- BUILT rows come from `releases/*.json` receipts. `predicted_change` is a
  MODEL range (anchor algebra), never a score.
- `proxy_report_20261023.json` holds report-only PROXY/SGMC numbers. They
  are never gates and never scores (see `mechanism_cards.md`).

Rebuild: `python scripts/build_ledger.py`
